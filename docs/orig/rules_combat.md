## 3. 일반 교전 피해식 (부대 대 부대) — 확정

출처 전체: `fidelity/combat6.md` §2·§3(복원 식·상수), 엔진 `CF::common_multiplier / attack_input_unit / siege_input_unit / defense_input_unit / normal_base / exchange_damage`. 실수 연산은 binary32, 어셈블리 순서 그대로(재배열 금지). 지정 이외 상수는 PE 읽기.

**M(X)** — `2AAF30(부대 X 또는 거점, n, 1)`  [확정, `combat6.md` §2]
```
a   = 231770(장수, 0, 0xFFF) = 통솔(부상 등급·관직·계급·개성 항 포함, §4.3). 장수 없으면 0
cap = int(pow(float(4*a/3), 2.0))        // 4a/3 정수 나눗셈
q   = min(cap, 병력) / n                 // 정수 나눗셈
base= float(sqrt(q)) + float(2a) + 200.0 // 141A4A664=1, 4A670=2, 4A67C=200
S   = (부대 +0x23 != 0) ? 8/10 : 1       // +0x23 = 혼란 게이지 바이트
M = S × base × (10/(n+9)) × ((200+사기)/300) × 인접지역효과 × 거친땅extra × 연계adj
  사기 = min(부대 +0x1A, 230460), 덤프 최대 130        // 141A4A6A0=200, 4A6AC=300(기본 분기)
  인접지역효과 = 2B2A90 (§4.4). 지휘관에 대한 233D70/234520/234AB0 중 하나라도 참이면 1.0
    (현재판 기계어 2026-11-19: 칸 = 부대 +0x152 `movzx ecx,word [rsi+152h]`, 0xBD10 미만; 2B2A90 반환 xmm0 → xmm10, 건너뛰면 xmm8 = 1.0; 마지막 인자 0이면 호출 안 함)
  extra = 1.5 if 진형(22F7A0) ∈ {6,14} && 지형코드 ∈ {5,6,8..11} else 1   // 141A4A658=150, 141A48064=150
  adj = (10 + 세력 정책 효과 0x26) × count/100 + 1.0    // count = 2B1B10: 같은 세력 이웃 중 장수 상성 >= 3, 범위 2 (141A4A22C=3, 4A220=2). 141A4A6C4=10, 난이도 분기 5
거점 M: T=dword +0x3C, 사기=byte +0x44, 능력=22C5A0(거점 담당 장수) 통솔, S 조건 byte +0x49, 지형항 없음
```
엔진: CF `common_multiplier`(구현). 연계 count는 엔진에서 중립(APPROX), 난이도·모드 사기 분기(141A48040=75/141A4804C=175 = 난이도 1의 (75+사기)/175)는 기본 분기만(APPROX).

**A(공격 입력)** — `2B4460(M, 부대, null, 진형, 1, 0)` / 대상이 거점이면 `2B4750`  [확정]
```
A = ((정책% × 진형 공격값)/100 × M) × 0.05 × (1 + 0.05×clamp(보정합,±10)) × (1 + 0.05×army+0x4B)
    [× (100+효과0x28)/100  : 효과 0x28>0 이고 2CBCB0(부대가 자기 거점 범위 안)]
    [× (100+e)/100         : 새 빌드, §11 e=주의 0x30, 지형 +0x42∈{2,4}, param_5!=0]
    [× 150/100 (집중 공격)  : 부대 +0x25>0 && +0x3E(지정 대상 id)==대상 id]      // 141A48920=150
  정책% = 41E4B0 = 100 + 진형 정책 효과(수송 진형 17..20은 100 고정)
  보정합 = 26BBE0 슬롯 5 + 슬롯 19 + 2A8160(부대 +0x10==1일 때만)
공성 A(2B4750): 진형값 = 2B4A10(공성 +0x84); 학익(5)은 세력 +0x193 비트1이면 +3; 보정 슬롯 6; army+0x4C
거점이 공격측: A = (34 (거점 id<=0x33) | 30 (0x34~0x3D)) × M × 0.05          // 141A488B4=34, 4A488C0=30
```
**공성 입력 `2B4750` 현재판 원문.** ABI의 첫 인자는 `float M`(XMM0), 뒤에는 유효성을 비교하는 두 객체, 진형, 정수 플래그 p5·p6다. 두 객체의 유효성 결과가 같으면 0을 반환한다. 공성 부대와 진형이 유효할 때 기초값은 `float((2B4A10(진형) + 학익가산) × 정책계수)/100`이다. 진형 5이고 세력 `+0x193` bit1이면 학익가산 3이다. 진형 정책 식별값이 19·20이면 정책계수 100, 나머지는 `41E4B0(부대,0)` 반환값이다.

부대 종류 `+0x10==1`이면 `보정합=2A8160(부대,p5==0)+26BBE0 결과+0x18+결과+0x4C`를 계산한다(뒤 두 값은 i32 효과 6·19). `26BBE0`에는 `(부대,0,&결과,p5==0,p5!=0 && p6!=0)`을 넘긴다. 보정합을 −10..10으로 제한한다. 반환 연산 순서는 `기초값 × M × (5.0/100) × (1+5.0×보정합/100) × 상태계수`다. 유효 부대이고 p5가 0이 아니면 상태계수는 `1+5.0×s8(부대+0x4C)/100`, 그 밖에는 1이다. 유효 부대와 p5≠0 조건에서 세력의 주의 항목 `0x30>0`이고 지형 객체 `+0x42∈{2,4}`이면 마지막에 `(100+효과)/100`을 곱한다. 상수와 반환 슬롯은 `2B4799..2B49DC` 현재판 asm에서 확인했다.

시설 사격 `192AF0`은 `2AAF30(대상 부대,0,1,1)`의 반환값을 XMM0에 두고 `2B4750(M,대상 부대,0,대상 진형,1,0)`을 호출한다(`192D55..192D97`). 반환 실수를 `16B180`의 A 입력에 사용한다. 시설 효과 레코드의 값 5/10/15는 이 공성 입력에 전달되지 않는다.

**`2B2A90` 정독 보충 (2026-11-25, R02; 디컴파일 + asm 꼬리 + PE 상수, 코드)** — 조사 목록의 「특정 개성이면 1.0」은 **기각**: `2B2A90` 안에는 개성 검사가 없다. 1.0을 돌려주는 곳은 (가) `2B2A90` 머리의 세력 번호 조건(번호가 1..51 밖이거나 46..50, 또는 세력 객체 무효), (나) 호출자의 위 세 지휘관 조건과 `2AAF30` 인수 4가 0일 때의 호출 생략이다. `2AAF30`의 호출 자리(`2AB31D`)는 `인수4 != 0 && (지휘관 무효 || 세력 무효 || (233D70==0 && 234520==0 && 234AB0(,0)==0)) && 세력 객체 유효`일 때만 부른다. 두 번째 호출자 `16C830`(1552B, 이름 미상)도 같은 세 조건(`233D70`·`234520`·`234AB0(,0)`)을 통과해야 `2B2A90`을 부르고, 걸리면 기본값 1.0(`fVar5`)을 쓴다.
- 「이웃 지역」 범위: 인수 1 = 칸 객체, `칸 +0x12`(u16, < 0x1F5) = 지역 번호 → 지역 객체(`world+0x6CAF0` 표). 점수 합에는 그 지역 자신과 **이웃 지역 최대 8개**(`지역 +0x56` u16[8], 슬롯 i는 `지역 +0x66` 마스크 비트 i가 켜진 것만, 번호 0 제외)를 넣는다. 각 지역이 기여하려면 `지역 +0x78`(u8, 소유 세력)이 인수 2의 세력이거나, 세력 효과 0x27 > 0이면서 `세력 객체 +0xEA + 소유 세력`의 하위 7비트가 0이 아닌 것(동맹 바이트)이어야 한다. 기여량 = `int(지역 +0x68(u16, 점령 칸) / 지역 +0x76(u16, 전체 칸) × 100)`(상수 `141345C4C` = 100.0). 소유 판정은 `+0x78`이고 중심 칸 소유(`22E650`)가 아니다.
- 비율 p: 기본 `141A4D6C0` = **4**. 세력 객체가 유효하고 `235150(세력)==0`(컴퓨터)이며 난이도(`3EC370`)가 3이면 `141A4ACEC` = **16**, 4 이상이면 `141A4AD10` = **24**. 이어 세력 효과 `22DB30(세력, 0x46)`을 p에 더한다. `S`를 점수 합이라 하면 기본 배율 = `S × (p/100) / 100 + 1.0`(`141345B98` = 1.0). 이 구간에는 `3EB2A0`(표준/숙련 게이트)이 없다.
- 꼬리 보정(기본 배율 뒤): ① **표준 모드**(`3ED7C0 != 0`): 기본 배율 > 1.0일 때만 `3EC490`(설정 객체 `+0xC4`)을 읽어 0이면 그대로, 1이면 × `141A4ACF8`(= **120**)/100, 2이면 × `141A4AD04`(= **140**)/100, 그 밖의 값이면 × 0으로 **전체 배율(1.0 항 포함)에** 곱한다(asm `2B2D88..2B2DC6`). ② **숙련 모드**(`3ED7C0 == 0`, 세력 유효): `3EC920(숙련 값 객체, 4 또는 5, 0)`의 퍼센트 `pct`를 쓴다. id 4 = `235150(세력) != 0`(플레이어 세력), id 5 = 그 밖. 배율 = `S × (p/100) / 100 × pct / 100 + 1.0`(asm `2B2E22..2B2E55`). 두 경로 모두 결과를 `368F20(4 또는 5, 기본 배율, 보정 배율)`에 한 번 알린다(표시/로그 계열로 추정, 미판독).

### 4.5 AI 평가 전력 (규칙 아님, 판단 입력)
`B5EC0`(옛 주소; AI 호출) = `병력 × M / 1000`(분할 1·실전보정 0). 통솔 80/병력 10000/사기 100 → 4600. 거점은 가상 부대를 만들어 평가. 출처: `REA_Analysis/mechanisms_20261017/능력치.md`("통솔과 병력"); `AI_TacticsMod/research/AI_Analysis/AI_전투력과_출진억제_쉽게읽기.md` §1(식 일치 확인). **판단은 복제하지 않음**(DESIGN 원칙).

현재 빌드 확인(2026-11-25, 조사 D14, 확신도 코드+기계어): `B6F50`(옛 `B5EC0`)은 `float(부대 +0x16 병력) × 2AAF30(부대, 0, 1, 0) / float(1A4B080)`이다(62바이트; 인수 `rdx=0` 거점 없음, `r8d=1` 분할 n, `r9d=0` 인접지역 효과 스위치 끔). `1A4B080`은 정수 1000(해제본 바이트 `e8 03 00 00`)이라 병력 단위가 아니라 고정 나눗수다. 그래서 위 M 식에서 **인접지역 효과·연계 항은 AI 전력에서 1.0으로 빠지고**(「분할 1·실전보정 0」과 같은 말), 통솔(능력 `a`, 부상·관직·개성 포함)·병력(`cap`·`q`와 곱)·사기(`(200+사기)/300`)·혼란(`+0x23`≠0이면 ×0.8)·진형 6·14의 험지 보너스(`extra`)가 들어간다. 진형 공격값은 들어가지 않는다. 확인 예: 통솔 50·병력 10000·사기 100 → 3660(`cap = (4×50/3)² = 4356`, `q = 4356`, `√q = 66`, `base = 66 + 100 + 200 = 366`). 칸 주변 합산 노드 `7EF50`(`CGetHexAroundFightingStrengthNode`)은 중심 칸을 뺀 1~반경 고리 안의 같은 세력 부대에 대해 이 값(`B6F50`)을 더하고 병력도 따로 더한다(반경은 판단표 노드 인수: functions.md 2.15 `7EF50` 행). 참고: ai/rulebase.md 3절 표의 「`B6F50` ... 전역 `1A48034`」는 해제본 바이트로 0이라 맞지 않고 나눗수는 `1A4B080`=1000이다(그 표는 고치지 않았음, 충돌).

## 6. 거점 수비대·시설 교전
- 거점도 병력이 있으면 자기 기록을 가져 **수비대 반격**이 같은 단계표로 돈다(`combat6.md` §1). 거점 M/A/B 가지는 §3.
- 거점이 공격측일 때 `16B180` 꼬리(`city_tail_16a1d0`): `D1 = D0×e3/100 + D0 + sel + A`, `A = D0×정책0x15/100`(도시반격강화), `sel`은 주둔 무장 개성 0x44(견뢰 +30)의 양/음 최댓값 택일(pos 시작 1, neg −1), `e3`=주 효과 종류 3(서주 "공장" 20, 필요 도시 2); 이후 방어 지휘관 특성 0x38 `D -= D/2`, 9999 상한(`fidelity/pre6_tactics.md` §3-2; CF `city_tail_16a1d0`). **적용 범위 확정(2026-11-07, `16B180` 디컴파일)**: 공격 기술자 종류가 5·6(도시·관문)이고 그 거점 id `< 0x34`(도시)일 때 방어 대상이 부대든 거점이든 항상 적용된다 — 수비대 반격(거점 → 부대 기록)도 포함(§14 C7 해결). 엔진: `TU_L2` 비트 4(기본 켜짐)로 수비대 반격 기록에 적용, `e3`은 상태가 없어 0(APPROX), 방어 지휘관 개성 0x38 절반은 미반영.

**격파 부대의 병력 처분.** `271E70`은 사기 0이면 `25A880`에 4번 인수 1과 사유 0 또는 3을 전달한다. 큐를 쓰는 경우 같은 값을 큐 레코드에 적는다(`272677..2726D8`). 새 빌드 함수 시작은 `271E70`이며 `2737A0`은 `273100`의 본문 중간이다.

`25A880`의 부상병 이전 분기에서 아래 규칙을 확인했다. L은 격파 부대의 잔여 병사(`+0x16`), W는 부상병(`+0x18`)이다.

- 통상 모드에서 이전이 허용되고 격파 부대와 그 지휘관의 소속 거점이 유효하면, 소속 거점 부상병(`+0x40`)에 `trunc(W×50/100)`을 보낸다. 유효한 상대 부대(`2340D0`) 또는 상대 거점(`2341C0`)의 이민족 분기에선 70%다. 두 술어는 소속 세력 46..50과 지휘·담당 무장 소속 거점 번호를 검사한다.
- 상대 부대가 있으면 별도로 그 부대의 부상병에 `L + trunc(W×50/100)`을 더한다(위 이민족 분기에서는 W의 30%). 결과는 20,000 상한이다. 상대 부대 없이 도시형 거점이 주어지면 `16AB90`으로 같은 양을 도시 부상병에 더한다. 소속 거점과 상대 도시 부상병 상한은 각각 가상 슬롯 `+0xC8`이다.
- 숙련 모드의 이 경로는 위 기준량에 설정 키 7 백분율을 곱하고, 각 전달량은 L+W를 넘지 않는다. 사기 0 직후에 상대 참조 없이 호출되면 소속 거점 귀환 분기만 설정과 유효성 검사를 거친다.
