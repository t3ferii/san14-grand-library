# 룰베이스: 임계값·가중치·판단표 (원작 AI)

자료 위치: 모두 `bt_exce.bin` 판단표 노드의 상수 인수이거나 `param_s.bin` 수식, 또는 EXE 코드 상수다. 아래 표는 **현재 빌드** 번호(군단 N)이며 전수 목록은 `thresholds.tsv`(비교 1459행 + 대입 1510행, 모든 숫자 비교·대입)다. 변수 이름 `보조값NNNN` 은 읽기용 임시 이름이다.

확신도는 각 행 마지막 열: 확정 = 판단표 노드를 직접 읽음 / 코드 = EXE 함수 상수 / 추정 = 의미 해석이 추정.

## 5. 부대 판단표 (N0~N110)

N7 선택 하나(104 노드)에서 우선순위대로 화염 회피, 위보 해소, 위보 시도, 화계 시도, 병참 회복, 인접 명승·지역 중심 점령, 독 회피, 적 병참 절단, 유리한 위치 이동, 인접 수리 순으로 검토한다. 화계 분기: 사기 50 이상, 근처 아군 수 제한, 성공확률 25 이상 등(옛 AI_행동패턴_읽기.md 6절). 부대 +0x140 이 0 이 아니면 N3 조건 146 에서 건너뛴다.

## 6. 군단 N10484~N10789: 군세 목적 갱신

모든 군세를 순회하며 행동종류가 12/0 이 아닌 군세의 대표 부대·관련 거점·사기·`게임보정설정(보정설정41)`을 읽고 출진판단기준2 = 2500, 추가값 = 2500 x 게임보정설정 으로 비교해 목적(CSpecifiedTroopsSetPurpose 19회)을 갱신하거나 군세를 생성한다(DepartureTroopsCreate 3회). 이는 군세 단위 재편성 단계로 읽힌다(추정).

## 7. BT 엔진 설정표 (C11E0, 현재 빌드 코드) — 메모리 풀 설정 (확정, L3b)

AI 초기화 `C11E0`(옛 `C0150`)이 `0000/bt_exce.bin` 과 `0000/param_s.bin` 을 읽고 조건 dispatch `C36A0` 와 노드 실행 `4F90C0` 을 등록하면서 넘기는 13칸 표는 AI 규칙이 아니라 **BT 엔진의 고정 크기 메모리 풀 설정**이다. `B2CF40`(엔진 초기화)가 표를 `B2CC80`(풀 구성)에 넘기고, 각 항목 = (블록 크기 바이트, 블록 수, 정렬 비트 수=2) 3칸 qword 다(`B2CC80` 이 `크기 > (1<<정렬)` 와 둘 다 0 이 아님을 검사하고 `(크기+0x10+정렬 올림)*개수` 만큼 확보). 값: 8B x 2000, 16B x 10000, 32B x 45000, 48B x 4000, 64B x 35000, 128B x 2500, 256B x 100, 512B x 700, 1024B x 10, 2048B x 700, 3072B x 600, 4096B x 5, 6144B x 5. 표를 안 주면(`param_2 +0x68` <= 0) 기본 7칸(32B x 1024, 64B x 1536, 128B x 512, 256B x 256, 512B x 128, 1024B x 64, 4096B x 32, 정렬 4)을 쓴다. 옛 문서의 "마스크·한도·비용" 해석은 정정(마스크 = 블록 크기, 값 = 블록 수).
