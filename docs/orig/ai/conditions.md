# 조건 함수 전수표 (현재 빌드 bt_exce.bin 기준)

- 기준: Steam buildid 25953386 의 `1a4a447d` 빌드, 조건 dispatch `C36A0`(옛 빌드 `C2610`) switch 167칸. 현재 판단표에 쓰이는 조건은 132종, 쓰이지 않는 칸은 35칸.
- 각 조건은 판단표의 조건 노드(kind 0x2252b2cb)가 가진 레코드(op, 인수)로 호출된다. **op 위치 확정(2026-11-08)**: 조건 노드의 `params[2] == 0`이고 op는 **`params[6]`**(0 기준), 그 뒤가 인수다. 인수는 대개 (객체종류, 문맥변수번호) 쌍이며 `BF790/BF4C0/BFBC0` 가 객체종류 코드를 세력/군단/칸으로 환산한다(아래 객체종류표).
- 확신도: **확정** = 현재 빌드 함수 본문을 직접 읽고 필드·상수를 확인, **추정** = 본문 구조 + 사용처 문맥(자식 노드가 어떤 명령인지)으로 의미를 붙임, **미해결** = 구조(읽는 필드·호출 함수)만 확정하고 의미는 못 정함.
- 현재 확정 계열 116(이 중 "확정(구조)/추정(이름·세부)" 표기 10) / 순수 추정 16 / 미해결 0 (L3 5차: 53·59·113·114·117·122·127·128·139·151·155·162·167 승격, 113·114·117·122·128·139 이름 정정) (사용 중 132종 기준; 2026-11-07 L3b 에서 미해결 22종과 추정 일부를 코드·메시지 id 로 확정/재분류. L3b 2차에서 10종을 필드·호출자 대응으로 확정 승격. 추정 32종은 이름·방향이 문맥 추정이거나 하위 함수 판정식을 끝까지 읽지 못한 것). 이전 자료(REA_Analysis/behavior_tree_validation.json)는 107종을 미해석으로 남겼다.
- 출처 표기: `AAE10 코드` = 현재 빌드 RVA 함수 본문(ghidra_full.py func 추출본), `문맥 증거` = 하위 노드 클래스, 그 외는 근거 문서 이름.
