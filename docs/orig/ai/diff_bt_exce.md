# bt_exce.bin 변경 기록 (옛 분석 시점 -> 현재 빌드)

## 요약

- 옛 분석(REA_Analysis/behavior_trees_current.json, SHA-256 `c90ef6da...`, 2026-10-15)의 bt_exce.bin 과 **현재 `0000/bt_exce.bin`(SHA-256 `315f16d0f27cf511`, 2026-11-05 15:21 갱신, Steam buildid 25953386)은 다른 파일이다.**..
- 네 트리의 노드 수: 세력 246 -> 246, **군단 10312 -> 10790 (+478)**, 군세 348 -> 348, 부대 111 -> 111. 군단 트리의 섹션 해시도 `0xeb10fb33` -> `0x72610cc7` 로 바뀌었다. 세력·군세·부대 트리는 노드 단위 완전 일치(구조·인수·텍스트).
- 따라서 **옛 문서(REA_Analysis/ai_mechanisms.md, behavior_tree_validation.json, AI_TacticsMod/research/AI_Analysis/all_behaviors/*_의사코드.txt, ai_trace/*.md, attack_decisions 등)에 적힌 군단 N번호는 현재 파일과 어긋난다.** `core_ai.pseudo.cpp` 와 옛 문서가 말하는 "11,017 노드"는 현재 11,495 노드(세력 246 + 군단 10,790 + 군세 348 + 부대 111)다.
- 변경 내용: 새로 들어온 조건 op 13(훈련담당관 있음)·op 14(모병담당관 있음) 사용, op 144 사용 증가(2 -> 8), op 1·24·115·116 등 사용 횟수 증가. 즉 **담당관(모병·훈련) 배정 판단과 외교·계략 후보 필터가 보강된 패치**로 읽힌다(추정: 변경 구간의 노드 구성 근거).
- 노드 종류(kind)는 새로 생기지 않았다(232종 그대로). 조건 op 13·14 만 새로 등장.
- 이전 문서의 군단 N번호를 현재 번호로 바꾸려면 아래 변환표(일치 구간)를 쓴다. 변경 구간의 옛 번호는 대응이 없다.
