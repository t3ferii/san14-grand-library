## 2. 지역 수입 (금·군량)

식은 지역 단위, 새 RVA 금 `2BF200`(옛 2BCE80)·군량 `2BECD0`(옛 2BC950). 담당관 없는 지역 금 96.9%·군량 98.3% 정확 일치, 담당관 있는 지역 금 92.0%·군량 85.9%(정확 일치 판정, DM 4차 1(a)). 같은 덤프를 "예측값 구간에 실측이 들어가면 일치"로 다시 재면 난이도 4에서 금 92.8%·군량 90.0%(담당관 지역; 난이도 2·3이면 0.03~0.2%로 무너짐, DF 1절).

**기본식(확정)**
```
v = int( ( sqrt(인구) × max(치안,50)/100
         + int((지역플래그×10 + 10×능력/100 + 100) × 단계계수 × 기준값 / 1000) ) × 영유칸/전체칸 ) × 배율/100
기준값: 금 = 상업(+0x44)·군량 = 농업(+0x46), 인구 +0x52, 치안 +0x54, 영유칸 +0x68, 전체칸 +0x76
배율: 금 65, 군량 30
단계계수(개발도 <100/<300/<600/<1000/이상): 금 10/12/14/16/18, 군량 10/13/16/18/20
능력: 금 = 지력(2), 군량 = 정치(3); 겸임 배율 담당 1곳 100 / 2곳 64 / 3곳 44 (4곳 이상 0, RM) ; 담당관 없으면 능력 항 0
```
이어서 순서대로: 담당관 개성(금 0x24, 군량 0x25)% → **세력 정책 효과**(금 0x35, 군량 0x34, `(100+e)×v/100`) → **군량만 계절**(7~9월 ×125/100, 지역 풍작 플래그 `+0x38 & 0x10`이면 추가 ×150/100) → **난이도**(컴 궁극 ×200/100, 9절). 도시 합산(`2BE030`): 지역 수입 합 → 발견된 명승의 수입 보정(`3306A0`, 아래 참조) → 담당관 정액(개성 효과 0x47 금/0x48 군량, 도시의 비부재 담당관 중 첫 값 ×1) → 상한(거점 vtbl 금 +0xB8/군량 +0xC0)까지 자름(L2 1절 E3).

**명승 수입 보정(현재 EXE 정적 분석).** `2BE030 → 3306A0`은 `world+0x85A90..0x85DB8`의 명승 포인터 101개를 순회한다. 유효하고 `+0x5F` bit0이 켜진 명승만 검사하며, 명승 칸 소유 세력과 소속 지역의 중심 칸 소유 세력이 같고 그 세력·소속 도시가 대상 도시와 일치하는 경우에만 집계한다(`22C300`, `22E8D0`, `22F5B0`, 도시 vt+0xB0). `+0x6D`가 1인 명승의 `22C0B0(명승,1)` 합은 금, 2의 합은 군량에 쓰이고, 각각 원래 양이 양수이고 합이 양수일 때 `int((float(합) / 100.0) × float(양) + float(양))`으로 계산한다. 3의 합은 별도 출력에 누적해 뒤쪽 병사 적용 블록에서 사용한다. 대상 도시 세력 종류 46~51은 이 블록을 건너뛴다. 합산 전에 적용되는 명승 개별 값은 기본 바이트 `+0x6E`에 담당관 개성 효과 `0x7B`에 따른 값을 더한다. 담당관이 유효하고 명승 칸 소유 세력과 같을 때 `f = 2 × 효과 × 기본값 / 100.0`을 구하며 0<f<1이면 +1, -1<f<0이면 -1, 그 밖에는 정수 변환한 값을 더한다(`22C0B0`, 상수 `1A4D260=2`, `1345C4C=100.0`). 이 경로는 기존의 "시설·건물 효과" 추정을 정정하며, 실행 중 값 변경 여부와 실게임 수입은 별도 검증 전이다.

`3306A0`의 다른 호출처 `906C70`은 조건을 통과한 경우 집계 건수를 UI 노드 `0x92`, 종류 1·2·3의 합을 각각 `0x98/0x9A/0x9C`에 표시한다. **종류 3은 병사 수입 보정이다**(현재판 정적 코드와 한국어 표시 대조). 명승 한 곳의 설명을 만드는 `357670`은 종류 1·2·3에 각각 `30F010` 번호 `0x843/0x844/0x845`를 넘기며, 한국어 `msgdata_exce` 1번 표의 원문은 각각 `금수입+%d%%`·`군량수입+%d%%`·`병사수입+%d%%`다.

`2BE030`에서 금·군량과 달리 종류 3의 합은 **뒤쪽 병사 적용 블록**에서 사용한다. `param_4 == 0`, 제외 세력 종류 46~51이 아님, 종류 3 합과 누적 징병량 `param_5[2]`이 모두 양수인 경우 `int((float(종류3 합) / 100.0) × float(징병량) + float(징병량))`을 계산하고, `도시 병력 상한(vt+0xC8) − 기존 병력(+0x3C)`을 넘지 않게 자른다. 이후 이 결과를 기존 병력에 더해 상한을 적용한다. 지역별 인구 차감은 앞선 기본 징병량 처리에서 이뤄지므로, 나중에 붙는 명승 증가분을 추가로 인구에서 차감하는 코드는 이 경로에 없다. 이는 정적 코드의 순서이며 실게임 대조는 아직 하지 않았다.

### 8.1a 컴퓨터 세력 시정 자동 배치 `263520` (노드 `53B80`, 난수 없음)
판단표 노드 `53B80`(CCommandExecutionGovernmentAutoNode, 세력 1)이 세력 사본(시정 5줄×7칸을 비우고 군사 번호만 남김)을 만들어 `263520(세력, 사본, 줄별 출력 목록[5])`을 부르고, 반환값 = 새 군사 후보. 고르기 순서 [Gemini g15 판독 2026-11-25, 지휘 세션이 정렬 비교·비용 조건·되돌림 순서를 디컴파일로 대조; 상수 값 미확인]:
1. **특례 플래그**: `world+0x90` 목록을 머리부터 돌며 `+0xCE`가 상수 배열(`1413B1A30`.., 0xE·0xF 포함 5개×2세트, 값 미확인)에 있고 다른 세력 소속인 객체를 찾아, 그 세력과의 관계값을 `DAT_141A4B1F8`/`1C8`/`1D4`/`1E0`/`1EC` 문턱으로 등급화해 등급 < 2면 플래그 = 1(뜻 미확인).
2. **후보**: `236260`이 주는 세력 무장 순서(머리부터) 중 `234FF0(무장,1)==0`(`+0xE6`≠1), `234AB0(무장,0)==0`, `+0x15E` 비트14 = 0, 정책(`+0x14D` < 0x79) 유효인 무장. 후보 가중치 = 대표 무장(사본 `+0x10` 번호, 군주로 보임)의 `+0x14C`가 2..6이면 `world+0x78CF8[그 값]`의 `+0x70+정책 분류(Policy+A0)` 바이트, 아니면 0.

### 8.3 풍작·흉조·계절 재해

**풍작.** 월 첫 순 15단계 `42A310 → 2BC4F0`은 `2BCFA0 → 2BC5A0 → 2BC510` 순서로 실행한다. `2BCFA0`은 4월에만 후보를 뽑는다. 통상 모드에서 `3EC0E0` 값이 2를 넘으면 중단하고, 숙련 모드에서는 설정 키 0이 0이면 중단한다. 후보 도시는 `2344D0`가 거짓이고 소유 세력 `+0x12` bit4가 꺼져 있으며, 소속 지역에 `234390`이 참인 곳이 없어야 한다. 초기 후보가 5곳 이상일 때 각 도시를 다시 검사해 `233DE0`이 참인 지역이 절반을 넘는 곳을 제외한다. 이어 첫 추첨 상수 40(`141A4C670`)을 적용한다. 효과 0x43(점술)을 가진 조건 충족 무장 또는 소유 세력 `+0x12` bit3이 있으면 우선 목록으로 나뉜다. 우선 목록 단계의 추첨 상수는 50(`141A4C67C`)이다. 숙련 모드의 설정 키 0은 전체 대상 수 계산에도 쓰인다.

- 메뚜기떼는 해당 지역의 중심이 거점 또는 관문인 경우 거점 군량이 2,000을 초과할 때 `clamp(1, 10000, floor(군량×P/100))`을 뺀다(`2D43D0`). 숙련 모드 상한은 40,000이다.
- 역병은 동일 지역의 거점·관문과 야전 부대에 병력 피해를 준다. 거점 병사가 2,000을 초과할 때 `floor(병사×P/100)`을 20..3,000(숙련 10,000)으로 제한해 뺀다. 거점 부상병이 1을 넘으면 `floor(부상병×P×2/100)`을 1..같은 상한으로 제한해 뺀다(`2E2E30`). 야전 병력은 100 초과일 때 같은 비율을 적용하되 손실 하한은 병사 1·부상병 0, 상한은 각각 500(숙련 2,500)이다.
- 지역 인구가 1,000을 초과하면 `floor(인구×P/100)`만큼 줄인다. 손실 하한은 10, 상한은 야전과 같은 500(숙련 5,000)이다. 지역과 부대의 무장에 대한 `2E2BD0`은 건강 등급 0·1이고 `234350`이 거짓일 때 난수 <6으로 등급을 한 단계 악화시킨다.

전파 추첨 기준값 `268CC0`은 역병이면 `clamp(런타임 하한, 10, clamp(1,15,floor(지역 인구/30000))−floor(A/2)+50)`이다. A는 진정식과 같은 담당관 지력·정치 보정값이다. 메뚜기떼는 `3FDAF0(15,1,지역 번호,1,0,0) + 런타임 값(1427D5644)`을 기준으로 쓴다. 지역별 추첨은 `29AF03..29AF38`에서 현재 년·월, 중심 칸, 인구, 치안 및 개발 원시값 합을 종자로 넘긴다.
