## 1. 병참 연결 판정

**규칙(확정, 덤프 99.77 % 일치 → 동맹 처리 뒤 ≥ 99.9 %)**: 전투 부대(덤프 부대 종류 1)의 병참 연결 = 「부대가 선 칸에서 **지휘관의 소속 거점 중심 칸**(`2AB620`, 무장 `+0xE2` 소속 거점 → 건물 `+0x10`)까지 이어지는 헥스 경로가 있는가」. 경로 탐색은 A*와 같은 코드(`185710` → `184D60`)를 **플래그 8**로 부른다. 플래그 8의 칸 통과 조건 `2C8C00(칸, 부대 세력)`: **지형 비용 ≠ 0이고 칸 소유자가 부대 세력에 대해 적대가 아님**. 목표 칸은 검사 없이 받는다. 칸당 비용은 균일 10000(거리만 본다). 결과는 부대 `+0x26` bit1(1 = 연결).

- 「적대」 `2CC630`: **무주(소유 0)는 적대(통과 불가)**, 중립 0x33도 적대, 이민족(0x2E~0x32)은 외교 상태 없으면 적대, 자기 세력·동맹·정전·속국은 비적대(`force+0xEA+상대`의 하위 7비트가 0이 아니면 비적대, `+0x194` 속국). 무주 칸 통과를 허용하면 거짓 연결 14건이 생기고 엄격 규칙은 0건 — 무주 통과 불가가 확인됨.
- 면제: 부대가 자기 거점 칸 위(`2CB6C0`), `234DE0`(특정 목록 소속), 세력 0x33·0x2E~0x32(중립·이민족), 수송 부대(실질적으로 면제: 덤프 단절 11건, 엔진은 APPROX로 면제).
- 시설(진·토성 등)은 병참 경로의 통과 조건이 아니다. 방벽·군사시설은 이동 경로에서만 막고(`184D60` 일반 분기 클래스 2·3), 병참은 칸 소유로만 끊긴다. 사용자가 기대한 「토성으로 적 경로를 막아 병참 단절」은 간접 효과(적 부대를 우회·지연시켜 이쪽 부대가 적 후방 칸을 칠하면 적 병참선이 끊김). `184D60` 321~385행에서 `(param_7 & 0xc)` 가지는 `2C8C00`만 부르고 시설 검사는 `(param_7 & 0x40) == 0`인 일반 가지에만 있다. **확정**(코드 + 덤프).
- 판정 시점(원작). 순 시작 단계 36 `429050`은 `25FA40 → 303020 → 278990(0) → 2901A0`을 실행한다. 현재 조건표의 36번은 항상 참이어서 1·11·21일에 모두 재판정한다([날짜](rules_time.md) 4.1절). `S14Event::SCheckConnectLogisticsAll` 슬롯 0 `3A75C0`도 `278990(0)`을 호출한다. 두 곳이 현재 추출본의 직접 호출자 전부다. `294670`은 외교 변화에서, `294B10`은 이동·칠하기 등의 부대/칸 단위 변화에서 `278290`을 부른다. `278990`은 `world+0x60`의 부대 목록을 모두 순회한다. 인자가 0이면 접속 변화 효과만 처리하고, 0 외의 값이면 정기 사기 감소도 수행하는 분기가 있다. 확인한 두 호출은 모두 0이고, 실제 5일 단위 정기 감소는 별도 `44DEE0 → 272720` 경로다.
- 엔진: 부대 칸에서 소속 거점 중심 칸까지 내부 칸이 비용 > 0·소유가 비적대(무주·중립·이민족 적대, 동맹·정전·속국·자기 통과)인 헥스 도달성(탐욕 최선 우선 탐색 + 소영역 flood; (세력, 출발 거점)별 한 번의 도달 영역 계산, 600칸에서 결정 못 하면 flood). 매일 이동·칠하기 뒤 판정(`supply_update`), `supply_level` 설정(기본 1) — **구현, 판정 주기·수송대 면제 APPROX**. 덤프 일치 99.9 %(RULES.md:63). 규칙 해시에 `TU_SUP`(1 = 단절 끄기, 진단용).

## 2. 단절·재연결 효과 (`278290`) — 확정

## 3. 정기 사기 감소 (`272720` → `268070`) — 확정

- 상태기계 `44DEE0` case 0x12: **날짜 % 5 == 0이고 하루의 마지막 소단계(11)** → 5·10·15·20·25·30일. 대상 = 모든 부대(종류 1·2, `2CB6C0`·`234DE0` 면제 제외). `사기 −= 268070(부대, 연결?)`, 결과 0이면 `25A880` 격파(rules_movement.md 9절).
- `268070`: 감소 = 지형 정기 감소값 `2B2330`(칸의 지형 객체 `+0x40` = fixdata 레코드 `+0x2F`의 거침 등급 값; 숙련이면 설정 게터 27 %) + **단절이면 +9**(`141A4C044`). 정책 효과 0x2B(%)가 칸 난수(`3FDAF0(100,…)`)보다 크고 `2CACA0`이 참이면 **지형 감소분만** 0. `2CACA0`은 부대와 세력이 유효하고, `world+0x150` 명승 목록에서 유효한 발견 명승(`+0x5F` bit0)이 부대와 같은 지역에 있으면 참이다(`22B9C0`으로 명승의 칸 `+0x5C`에서 지역 번호를 읽음). 개성 효과 0x0D(사기감소 증감)는 `271E70`에서 `bonus = int(L x 합/100)`(0이면 부호대로 ±1, 손실 L' = L − bonus)로 반영(L1).

- 엔진: `periodic_morale`(날짜 % 5 == 0, 하루 끝, 수송·이민족·중립 제외, 같은 날 사기 ≤ 0이면 즉시 소멸). S18 비트 1(기본 켜짐): 지형 사기 감소 표를 레코드 `+0x2F`로 정정하고 **연결 부대에도 적용**. 연결 부대의 회복 항은 엔진에 없다(회복 미모델 → 덤프의 상쇄는 재현 안 됨, APPROX). 지형 +0x30 오기는 `+0x2F`로 정정(command_audit.md 15절 레이아웃 정정, 아래 9절).

## 4. 군량 소비·정산 (원작 구조 — 확정, 엔진은 L2에서 교체)

원작은 **부대가 군량을 직접 보유하지 않는다**(덤프의 행군 부대 512바이트 레코드에 순당 감소하는 u32 후보 0개). 거점이 연결 부대의 소비를 **순(1·11·21일)마다 대신 지불**한다.

흐름(`305390` → 순마다 거점 목록을 돌며 → `2DEAC0` 수비병 → `2DEE10` 부대 순; 부대 소비 `26AD80`(모드 1은 부대별 캐시) → `26AF80`; 부족 시 `2CEBB0`; 수비병 부족 시 `2CEE50`):

- 대상 = 연결된 부대(`army+0x26` bit1). **단절 부대는 소비 0**(덤프: 단절 부대만 가진 세력의 군량 순변화 = 수비병 계산분, 잔차 중앙 −0.1; 연결 부대만 있는 세력의 부대 소비 = 모형의 0.95~1.0배). 지불자는 도시(`22C1F0`); 관문의 부대·수비병은 관문 칸이 속한 지역의 도시가 낸다.
- 부대 소비 `26AF80`(상수 PE 확인: `141A4CF98`=40, `CF80`=30, `CFA4`=3, `CFB0`=75, `D23C`=1, `D244`=1):
  `x = (1 − (1 − c/(F·s)) x 75/100) x base x (3s + 1000)/1000 − e11·base/100 − 개성0x14·base/100 + 적지항`, `need = max(0, int(x))`,
  `base = max(1, (병력+부상병) x 40/30/10) x (100 − 타일 경감)/100`. `s` = 부대 칸에서 소속 거점 칸까지 경로 칸 수(`2B1F00`/`185710`, 최소 1), `c` = 경로 비용 합(최소 1), `F` = 설정 객체(`DAT+0x73868`)의 지형 비용 `BF1B0`(런타임 값; **덤프로 맞춰 F = 300**: 11→21일 창에서 부대가 전부 연결이고 수송대 없는 세력 238개의 (군량 감소 − 수비병 계산분)/모형 소비 중앙 0.9992; F=225 0.80, 250 0.87, 275 0.94, 325 1.06, 350 1.12). `e11` = 정책 효과 0x0B 군량소비감소, 개성 0x14 군량소비 감소(조건 판정 포함). **적지항** = 칸 주인이 다른 세력이고 동맹·휴전이 아니면 주인 세력의 정책 효과 0x43 x (플레이어 세력이고 난이도 ≥ 4이면 2, 아니면 1) x base / 100(`235150`은 **부대 소유 세력**이 게임 플레이어 세력과 같을 때 참. `26B207` 호출 직전 `22E2A0(부대)`). 난이도 3은 `141A4AE98`=150을 정수로 100으로 나눠 배수 1, 4 이상은 `141A4AEA4`=200으로 배수 2. 효과 0x43은 부대의 현재 지역 소유 세력에서 조회한다. 옛 `2695D0`의 `− int(효과 0x40 x 기본/100)` 항은 새 `26AF80`에서 **삭제**(엔진은 처음부터 미모델).
- 진·요새(효과 18) 반경 2 안 자기·동맹 부대 소비 30 % 감면(`300970`/`2FE580`이 매 갱신 `hex+0x19`를 지우고 다시 씀, 확정).
- **부족 처리**: `2CEBB0`의 둘째 인자(부족 비율)는 쓰이지 않는다(디컴파일 확인). 사기 −= 3 x (9 + 지형 정기 감소)(`268070` 모드 0 = `141A4C044` 9 + `2B2330`). **병력 손실 없음**, 지불은 남은 재고 전부.
- 거점 수비병 `2DEAC0`: 고지 = `max(1, (병력+부상병) x 10/30/10)`(`141A4CF8C` = 10, 덤프 294창 비율 중앙 0.9996 → 거점 군량 소비 병력//30/순), 태수 개성 0x46으로 가감, 지불자는 도시. 부족하면 `2CEE50`: 병력 −= `max(400+rand(200), (30 − 매력/15) x 병력/100) x pct/100 + 1`, `pct = max(1, (고지 − 재고) x 100/고지)`.
- 덤프 기준(2차 F, 4차 1(b)): 병력 불변 도시-순 20,619건 중 군량 감소 ≥ 병력//30이 95.3 %, 정확히 병력//30이 49.8 %(나머지는 부대 보급 유출), 군량 상한 도달 도시의 평형값 = 상한 − 병력/30(296,667 = 300,000 − 100,000/30). **소비는 순(01/11/21) 단위, 일 단위로 넣으면 군량이 0으로 붕괴**.
- 엔진(`battle.cpp unit_food_need`/`unit_food_settle`/`garrison_settle`/`base_payer`, `update_units`의 tick(1·11·21일)과 `rules.cpp day()`의 `turn_day`): 위 식 그대로 구현. 부대는 군량 보유 없음(`Unit::food` = (병력+부상병) x 3 파생값), 출진·이민족 출진·`inject_sortie`의 군량 차감 제거, 수송대만 군량 운반, 단절 부대 소비 0, 부족 시 사기만. **구현**(식 구조 높음, F=300 중상). 남은 차이: 지불 순서(원작은 부대 목록 순, 엔진 배열 순), 정책 0x2B 난수가 지형 항을 0으로 만드는 분기.
