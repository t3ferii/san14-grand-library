## E5. 능력 변경 칸 5개와 병합 `2EE790`

- **주(州) 지배 효과**(18종 표, `+0x30` 주 번호 1..17, 필요 도시 수 `+0x95`): `2AFAB0(세력, 종류, &플래그, 0)`이 종류 1..13을 합산(`2B4DC0`이 해당 종류 주를 모으고 `2C6450` 통과 주마다 `2AD6C0`). 전투 연관: 종류 3 = 서주(5) "공장" 값 20, 종류 4 = 20(필요 도시 2). 전체 17주 표는 `fidelity/pre6_tactics.md` §3-3(확정: 유주 1→46, …, 형주북부 6→20·7→5 등; 의미 이름은 종류 1·2·7만 문헌 대조). 도시 공격자 `16B180` 꼬리에서 `e3`로 쓰임(`rules_combat.md` §6).
- 효과 번호 이름공간: 정책 효과(101행, `policy_effect.json`) / 개성 효과(132종) / 개성 id(356) / 주 효과(종류 1..13)는 모두 다르다. 예: 정책 0x15 = 도시반격강화, 개성 효과 0x15 = 상태이상 무효(`pre6_tactics.md` §3-0).

## E10. 명품

fixdata 명품 표(`0x32A6F`, 22B × 202, 유효 1~151; 152~201은 예비). `+0x0E` 종류(28종), `+0x0F` 능력(1 통솔·2 무력·3 지력·4 정치·5 매력), `+0x10` 능력값(1~10), `+0x11` 특수효과(1 퇴각확실 = 명마 10개, 2 수명연장 = 의서 3 + 마누 법전), `+0x13` 가치, 수여·몰수 불가는 옥새·동작 둘뿐. 능력 getter `231770`의 명품 항은 소유 항목 중 **가장 큰 가산치 하나만**(여럿의 합이 아님, 항목 ≤10). 이동·전투 직접 효과 필드는 없음(퇴각확실만 퇴각 판정에 영향, 코드 못 읽음). 엔진: 소유 `treasure_owner[152]`(시나리오 37/151 소유), `Game::ability`에 소유 명품 합(상한 100; **원작은 최대 하나·≤10이므로 APPROX**), 소유 이전은 사망→군주, 포로→포획 세력 군주(최소 구현). 출처: `worldmap_spec_b.md` §5.4; `worldmap/appendix_treasures.md`; `REA_Analysis/mechanisms_20261017/능력치.md`; `worldmap_s7.md` §5. → 충돌 E12-3.
