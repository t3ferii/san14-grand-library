## 2. 외교 공통

### 2.1 판정 흐름 (확정, command_audit.md:86)

결과 함수 `1DB900`(Diplomacy 클래스 단계 20) → AI `1408080B0` → 판정 `808930`(외교관 보너스 `806DA0`) → 수락 `326ED0` → 효과 `81F290` → 종류별 효과 함수.
`808930`/`806DA0`은 외교 AI가 성공률(`param_4`)을 종류별 문턱(`141A4BE88`/`94`/`A0`/`AC`/`B8`)으로 1/2 등급으로 바꾸는 **판단** 코드라 복제하지 않는다(command_audit.md:283).

### 2.2 성공률 공통 식 (확정, command_audit.md:88-98)

`성공률 = (제공' − 요구 × 3/10) × 100 / 제공'`
* 제공' = 제공 × (정책 효과 0x17 가산) 이며 종류 4·8은 외교관 개성 효과 0x40 가산도 곱한다. 정책 0x17 항은 개성 배율을 곱하기 전 원값 V에서 구한다: `제공' = V×(100+개성0x40)/100 + max(1, V×정책0x17×1/100)` (S15 정정, command_audit.md:432).
* 외교관 정치' = 정치 + 정치 × 개성 0x40 / 100 (`2B50A0`). (r5_research에서 0x40 = 논객, 정책 23 = 종횡술로 부름. r5_research.md:표 친선 4행.)
* 제공 가치 `324320`(종류 4·5·8·9 공통), 첫 비-0 분기만 센다(확정, command_audit.md:430):
  금 > 0 → 금(상수 `141A4B3AC`=100, ÷100); 아니면 군량 > 0 → 군량×10/50(`141A4B3B4`); 아니면 명품 → min(명품 `+0x49`, 50)×`141A4B3BC`(옛 서술의 「도시 +0x49」는 오기: 이 경로는 `world+0x77B18` 명품 표의 가치, structs.md 명품 절과 일치) [Codex 판독 2026-11-25·미검증]; 아니면 무장(최대 3, `26C510` 합); 아니면 지역 → 3000 + 100×지역 +0x68(`141A4B3C4`/`3D0`). 금과 군량을 함께 내도 금만 센다.
* 무장 가치 `26C510`(확정 구조): `((600×#능력≥100 + 180×#≥90 + 20×#≥70 + 100×#(등급 3 개성) + 200[전법에 학습 가능 ID(31..130, >139)가 하나] + 200[정책 +0xA1 bit0] + 기본 능력 5개 합) × 50) / 10`, 하한 1000(`141A4B3E8`), 개성 효과 0xF 보유 시 +3000(`141A4B400`). 개성 등급 3은 `+0xBE==3`이다.

### 2.3 수락 `326ED0` (확정, command_audit.md:96)

우호도 등급 5(≥100, `2AF940`)면 무조건 성공, 아니면 `roll100 < 성공률`. 이민족 군주가 도시에 있으면 친선은 항상 성공(`808930`).
* 원문은 등급 5(≥100)만 기록했다. 나머지 등급 경계는 미해결.

### 2.4 우호도 (확정, command_audit.md:97, 61-62)

* 변경 지점은 `2719C0` → `25A080` 한 곳. 양쪽 방향 모두 `+= delta`, 각각 0..200으로 자른다.
* 시간 경과에 따른 자연 변화는 없다. 덤프에서 우호도 변화 총 2,835건(2,179,638 쌍·순)은 전부 이벤트다: +10/+20 친선, −5 동맹 실패·공격 요청, −8 계략 실패, −15 공격 요청, ±30 이상 = 함락·파기·멸망 (command_audit.md:195-216).
* 변경 위치: 쌍 기록은 세력 레코드 `+0x13+P`(슬롯 P)에 있다(r5_research.md: 1022 합본 AI_AND_INTERNAL_AFFAIRS 127).
* 동맹 중 우호도가 105로 고정된다는 가정은 틀렸다(10절).
* 동맹·외교 기간: 상태 바이트 `+0xEA` 하위 7비트 = 남은 개월, 월 단위로 줄어 만료 시 해제(`2EE080`이 씀)(command_audit.md:63).

## 3. 종류별 외교

### 3.1 친선 4 (확정)

* 요구 `324F20` = `((200−F)² / 8 × k/100) + (100 − 정치'/2) × 상대 도시수`, 50 단위 내림 (command_audit.md:92). k의 원문 값은 문서 미기록.
* 성공(`823690`): 새 우호도 = `max(10, F + min(잉여×10/(1070−정치'), 40) + int(10×효과8/100))`, 잉여 = 제공 − 요구 (`141A4B210/218/220`). 효과 8은 정책 효과(행위 세력 값이 0이면 대상 세력 값). 이민족 대상이 F < 50이면 상한 `min((F+1)/2 × 제공/1000, 19)`와 바닥 1(`141A4B240`). (command_audit.md:98)
* 이민족 군주가 있으면 항상 성공(`234250(T)`: 대상 세력 T의 군주가 유효하고 군주 소재 거점 `+0xE2`가 1..0x3D(61, 도시와 관문)이면서 T 번호가 0x2E..0x32일 때 1; 「도시에 있는」 한정은 코드보다 좁다. `326ED0` kind 4에서 param7=1이면 이 검사가 관계등급 검사보다 먼저 1을 돌려준다) [Codex 판독 2026-11-25·미검증]. 이민족 교역국 시스템과는 별개 경로(6절).

### 3.2 동맹 5 / 파기 6 (확정)

* **AI 동맹 제안의 자원 검사 `525C0`→`9D930`는 아래 3.7절대로 기간 비용 `324180`만 비교하고 `3240F0`(우호 부족 가산)을 부르지 않는다. `3240F0`은 제안 제출 때의 군사 조언 성공률 `324540`(종류 5)에만 들어간다** [Codex 판독 2026-11-25·미검증]. 아래 일반 식은 그 두 경로의 합이다.
* 동맹 요구 = `3240F0`(우호 부족: F<100이면 `(100−F)(1070−정치')/10`) + 기간 비용 `(개월−5)×100 + 150×D + 4000`. r5_research.md 동맹 5행에는 기간 비용을 `max(4000, …)`로 적었으나 최근 audit(command_audit.md:98)에는 max 표기가 없다. D = 도시수 비교(`ours<theirs ? 2·theirs−ours : theirs`, 정의는 r5에서 옮긴 것 → 추정).
* 성공(`822710`, `2EE080`): 기간 = 남은 개월 + 지정 개월, 최대 48(`2EE080`의 0x30). 우호도는 최소 50으로 올림(`141A4B26C`). 실패 우호도 −5(`141A4B274`).* 파기(`8229B0`): 동맹 중에만 가능, 성공률 판정 없음. 관계 해제, 우호도 −50(≥110이면 60으로), 다른 일반 세력 전부와 −5(`141A4B2B8`, 이민족·중립 제외), 평판 −20, 그 세력 무장 중 충성 ≤ 100인 비혈연은 `(군주와 주의 같으면 0/다르면 10) + roll(2)` 하락(`141A4B2D8`). (command_audit.md:99-100) **보강(2026-11-25 5차, 출처 표시, [Sonnet 판독 2026-11-25·미검증, s11])**: 충성 하락 대상은 「파기를 낸 쪽(A)」 군주의 무장을 순회한다는 코드 읽기이고(「그 세력」 표현은 모호, A 쪽이면 일치하는 가설), 난수 호출은 `roll(2)`가 아니라 `3FDFF0(B2E0)` 무장당 1회(`B2E0` = 2인지는 미확인)이다. 사자 `[1]`은 사자 무장 P이고 `1F1000`은 T 유효·P 유효·`233BE0(P)==0`만 검사한다(동맹·우호도·명령서 검사 없음).
* 세력 평판 = 세력 `+0x1BE`(short, ±1000, `2255F0` 호출 22곳, 단계표 `1413A9DDC`). 무장 공적과 다르다(S15, command_audit.md:457).

### 3.3 항복 권고 7 (판정식과 이전 경로)

* 판정 `3263B0`(S10), 효과 `824090`. 실패 시 우호도 −20(`141A4B37C`).
* 현재 빌드 `3263B0`의 종류 7 분기. 경과일 `G+0x450 > 360`, 인접 판정 `2C9890`, 일반 제3 세력이 하나 이상(46..51과 당사자 제외), 권고하는 쪽의 도시 수 ≥ 4×상대 도시 수, 상대 도시 수 <5, 전체 병력 ≥ 3×상대 병력이 필요하다. 전체 병력은 `2AF5E0(세력,1,0)`으로 거점·부대 병사를 더한다. 상대 군주가 우리 군주 또는 교섭 무장을 혐오하면 실패한다.
* 점수 `S = trunc(정치′ + B + R + (A−D)/5.0 + (A/D)/2.0 − 상성차/7.0)`. `정치′`는 교섭 무장 `2B50A0(무장,3,0x40,1)`의 반환값, `A/D`의 A와 D는 양쪽 도시 수다. `B=10`은 `32EE60`이 반환하는 유효 세력이 상대와 일치할 때, 그 밖에는 0. `R=20`은 상대 군주와 교섭 무장이 배우자 또는 의형제일 때, 그 외에는 상대 군주의 친애 목록에 교섭 무장이 있으면 10, 아니면 0이다.
* 상대 군주의 거점이 속한 지도 영역을 기준으로 양쪽의 유효 부대 병사를 합산한다(부대 현재 지역 `+0x35` 대조, `234DE0`이 참인 부대 제외). `P = max(0, trunc(권고측 영역 병사 / max(1, 상대 영역 병사 + 상대 거점 병사)))`, `T = trunc(P² / D)`. 성공 조건은 `min(T,30) + Y + Rng(Y) ≥ trunc(100 − 우호도/4.0 + 상대 군주 매력/5.0)`, `Y=trunc(S/2.0)`. `Rng(Y)`는 `3269DB → 3FDAF0`의 원작 난수 호출이며 Y<2이면 0이다. 상수는 현재 PE `141A4B5D4..141A4B67C`와 `141345C4C`를 대조했다.
* 성공 결과 `824090`은 `27BB90`로 종국·플레이어 패배 분기를 검사한다. 이 함수가 0을 반환하면 `2A44C0(항복한 세력, 인수 세력, 0)`을 실행한다. 1이면 `32D990` 경로로 간다.
