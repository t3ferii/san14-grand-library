# 공개 자료와 로컬 생성물

## 공개 저장소

직접 작성한 설명·형식 명세·조사 색인·파서·분석 자동화·합성 테스트·호환 규약을 포함한다. 초기 자료는 기존 San14Sim 대도서관과 origlib, AI_TacticsMod의 Ghidra 스크립트에서 이관했다. 파일별 원본 해시는 `docs/PROVENANCE.json`에 기록한다. 게임 권리자의 권리를 이 프로젝트의 라이선스로 부여하지 않는다.

## 각자 PC에만 보관

원작 EXE와 게임 데이터 원본, 해제본, Ghidra 프로젝트, 대량 디컴파일·asm·원작 바이트 덤프, SQLite 코드 캐시, 세이브, 사용자 로그, 게임 이미지·음원은 저장소·PR·Issue·CI artifact·Git LFS에 올리지 않는다. `.gitignore`와 공개 자료 검사는 실수 방지를 돕지만 검토를 대신하지 않는다.

초기 대도서관의 전수 AI 트리 출력(`pseudo_*.txt`), 원작 판단표의 대량 추출 표와 이전 조사 전수 목록은 공개 패키지에서 제외했다. 관련 설명·형식·함수 및 직접 작성한 해석은 주제별 문서에 남아 있다. 필요한 원본 데이터는 각자의 설치본을 `origlib`로 조회한다.

## 외부 도구

도구 바이너리는 저장소에 동봉하지 않는다. 준비 프로그램이 고정한 공식 릴리스에서 다운로드한다. 버전·URL·SHA256은 `tools/dependencies.lock.json`, 출처와 라이선스는 `THIRD_PARTY.md`에 있다. 도구의 라이선스를 우리 프로젝트 라이선스로 바꾸지 않는다. Steamless의 목적과 제한은 해당 프로젝트 문서를 따른다. 게임 소유·이용·분석에 적용되는 조건은 사용자와 환경에 따라 별도로 확인해야 한다.
