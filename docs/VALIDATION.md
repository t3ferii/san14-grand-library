# 도구 검증 기록

2026-11-24, 실제 Steam CE KO 설치본과 별도 사용자 작업 폴더에서 확인했다. 원작 조사 문서의 이관은 모든 역사 해석을 새로 검증했다는 뜻이 아니다.

## 신규 캐시 생성

- Steam 자동 탐색, buildid `25953386`, 설치 EXE SHA256 `782cf229a56cdde2b95399e0e7536740b3f5e96bea702679365e4dad061abdce` 확인.
- Python·Java·Ghidra·Steamless의 고정 공식 배포본 다운로드·압축 해제·SHA256 확인 실행. 시스템 PATH나 게임 설치 파일을 변경하지 않음.
- Steamless 옵션 `--keepbind --keepstub --recalcchecksum`으로 작업 사본 생성. 기존 대도서관 분석 EXE 전체 SHA256 `1a4a447d14e68c40ad2a5107c29c7341c10eee8fc297a7b35032900c341dbcaa`와 일치.
- 기존 Ghidra 프로젝트·추출본을 가져오지 않고 새 영구 프로젝트를 생성해 최초 분석. 함수 **55,614개**, 문자열 25,919개, 분석 시간 초과 없음.
- 전체 **312/312개 샤드** 추출. 함수 55,614개, 호출관계 899,385행, 데이터 참조 279,668행, vtable 후보 32,757행. 디컴파일 실패 **6개**는 실패 목록과 `ready_with_decompile_failures` 상태로 명시.
- SQLite 색인과 행 수·무결성·표본 본문 검증 통과. `ready.json`의 `reused_export`는 `false`.
- `func 862030`이 포함 함수 `862010`을 조회하는 것, `callers 862030`, `bytes 862010 --length 16`, 표본 `9309C0` 확인.
- 동일한 `prepare.ps1` 재실행과 `-VerifyOnly`: 다운로드·분석 없이 `[cached] ready`로 완료.
- 작업 종료 후 설치 EXE SHA256은 최초 값과 동일.

이 환경에서 최초 Ghidra 분석은 약 22분, 전체 함수 추출은 약 44분 걸렸다. 최초 준비에는 1시간 이상 걸릴 수 있으며 장치·네트워크·분석 결과에 따라 다르다.

검증 도중 Windows에서 SQLite 연결이 닫히기 전에 임시 색인을 교체하던 문제와 잠긴 바이트를 먼저 읽던 동시 준비 오류를 수정했다. 최초로 시작해 둔 수정 전 프로세스는 색인 교체에서 종료했으며, 현행 명령을 재실행해 저장된 분석·완료 샤드를 재사용하고 준비를 마쳤다. 이 복구 때문에 최초 분석과 전체 디컴파일을 다시 실행하지 않았다.

## 기존 로컬 캐시 재사용

동일 EXE 해시의 기존 추출본을 별도 캐시에 `-ReuseExport`로 가져오는 경로도 확인했다. 기존 저장 분석본은 함수 **55,612개**, 디컴파일 실패 **6개**였다. 신규 분석 결과와 구분하며, 그 차이만으로 원작 코드가 달라졌다고 해석하지 않는다. 조회·표본 검증·재실행 캐시 재사용을 통과했다.

## 공개 주소에서 시작

- 인증·Git 명령 없이 공개 bootstrap을 받아 저장소 ZIP을 내려받고 Steam 설치본을 자동 탐색.
- 빈 별도 작업 폴더의 `bootstrap.ps1 -Doctor`: Python 자동 다운로드·실행과 설치 경로 확인 통과.
- 기존 캐시를 지정한 공개 bootstrap 전체 실행: 추가 다운로드·분석 없이 검증 후 완료.
- 원작 파일·코드 캐시를 GitHub에서 내려받는 기능은 없음.

## 코드·문서와 운영

- 합성 회귀 **20개**: 인덱스·조회, 함수 내부 RVA, 잘못된 빌드·불완전 캐시·실패 표시·체크섬·ZIP 경로·원본 보존·재사용·동시 잠금·모드 충돌을 검사.
- GitHub Actions는 Windows·Ubuntu에서 실행. Windows 준비 경로 시험 1개는 Ubuntu에서 건너뛴다.
- 공개 파일·문서 링크 검사: **83개 파일, 오류 0개**. PowerShell 진입점 3개 구문 검사 통과.
- 공개 Git tree의 83개 파일에도 EXE·DLL·게임 데이터·코드 캐시·로그가 없는 것을 확인.
- main의 외부 PR에는 필수 Windows/Ubuntu 검사, 코드 소유자 승인 1개, 대화 해결, 새 변경 시 이전 승인 취소를 설정. 단독 관리자 유지보수 예외는 CONTRIBUTING에 공개.

게임 실행·실게임 모드 호환·모든 역사 문서의 개별 의미 검증은 수행하지 않았다. 도구·정적 검사 성공을 해당 검증으로 대신하지 않는다.
