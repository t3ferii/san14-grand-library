# 도구 검증 기록

2026-11-24 검증을 진행 중이다. 이 문서는 실제로 확인한 항목만 갱신한다. 원작 조사 문서를 이관한 것은 그 문서의 모든 사실을 다시 검증했다는 뜻이 아니다.

- 실제 Steam CE KO 설치본의 SHA256 확인: 지원 프로필과 일치.
- 공식 Steamless 3.1.0.5를 고정 옵션으로 실행한 작업 사본: 기존 분석 EXE 전체 SHA256과 일치. 원본 EXE는 보존.
- 자동 Python·Java·Ghidra·Steamless 다운로드와 ZIP SHA256 확인: 로컬 자동 준비 과정에서 실행.
- 새 영구 Ghidra 프로젝트의 최초 분석: 진행 중.
- 기존 동일 해시의 로컬 추출본을 별도 캐시에 재사용: 함수 55,612개 색인, 표본 의사코드·호출자·원작 바이트 조회 통과. 디컴파일 실패 6개를 명시적으로 보고. `reused_export: true`이며 완전 신규 분석 결과와 구분한다.
- 재사용 경로 재실행: 다운로드·분석 없이 캐시 검증 후 완료.
- 합성 회귀: Windows 17개 통과. GitHub CI는 Windows·Ubuntu 모두 성공(Windows 전용 준비 경로 시험은 Ubuntu에서 건너뜀).
- 공개 파일·문서 링크 검사: 83개 파일, 오류 0개. PowerShell 진입점 3개 구문 검사 통과.
- 신규 전체 추출과 공개 URL bootstrap 검증: 완료 후 결과를 기록할 예정.

게임 실행·실게임 모드 호환 테스트는 이 도구의 검증 범위가 아니다.
